Uma sessão, vários caminhos

Experimentar.
Criar. Descobrir.

O ponto de partida foi a criação de uma página web sobre um tema escolhido por cada participante. A partir daí, abrimos a porta a diferentes áreas da tecnologia e mostramos como se relacionam.

💡
01 · Ideia

Escolher um tema

Cada participante começou por algo que já conhecia ou gostava. A tecnologia entrou ao serviço da criatividade.

🌐
02 · Construção

Criar uma página

HTML, CSS e JavaScript foram usados para transformar conteúdo numa experiência web visual e interativa.

🧠
03 · IA

Aprender com apoio

A Inteligência Artificial foi apresentada como copiloto para explorar, questionar, testar e melhorar soluções.

🚀
04 · Exploração

Ir além da Web

Arduino, Defold, jogos 2D/3D e Lua mostraram que programar pode levar a caminhos muito diferentes.
